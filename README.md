# AI Startup Factory

AI-powered multi-agent startup planning system built with n8n, OpenRouter AI, Google Sheets, Gmail, and Tally Forms.

## Overview

AI Startup Factory transforms a simple startup idea into a complete business plan using multiple AI agents.

The system automatically performs startup planning, market research, pricing analysis, and marketing strategy generation, then delivers the final report through Gmail and stores the results in Google Sheets.

## Features

* Startup Idea Collection
* AI Startup Planner Agent
* Market Research Agent
* Pricing Strategy Agent
* Marketing Strategy Agent
* Automated Gmail Reports
* Google Sheets Integration
* Multi-Agent Workflow Automation

## Tech Stack

* n8n
* OpenRouter AI
* Tally Forms
* Gmail
* Google Sheets
* AI Agents

## Workflow

1. User submits startup idea through Tally Form
2. Startup Planner Agent creates business concept
3. Market Research Agent analyzes demand and competition
4. Pricing Agent generates pricing strategy
5. Marketing Agent creates marketing plan
6. Results are stored in Google Sheets
7. Complete report is delivered via Gmail
